# ⏸️ 暂隐藏栏目 · 提醒与恢复

> **用途：提醒所有协作者——「服务项目」与「创客大赛」两个栏目目前被暂时隐藏**，
> 内容真实性确认前不要上线；本文档记录隐藏范围与恢复方法。
> 最后更新：2026-08-24（提交 `98e3bf96`）

---

## 一、为什么隐藏

「服务项目」（`services.html`）与「创客大赛」（`contest.html`）的展示内容
不一定与事实完全一致，暂不适合对外展示。因此在**不做删除**的前提下，从
前台所有可见入口隐藏了这两个栏目，文件 / 接口 / 数据库 / 后台管理全部保留。

## 二、隐藏了什么（改动范围）

| # | 文件 | 改了什么 |
|---|---|---|
| 1 | `ruoyi-ui/public/*.html`（12 页：about/article/contest/home/industry/join/news/policy/profile/service/services/talent） | 顶部导航里两栏目的 `<a>` 链接替换为 `<!-- 暂隐藏导航：服务项目 / 创客大赛 -->` 注释 |
| 2 | `ruoyi-ui/public/home.html` | 首页「04 服务概览」整段 `<section id="services">` 移除（分类卡片 + 浏览全部按钮），原位置留说明注释 |
| 3 | `ruoyi-ui/public/service.html` | 面包屑里"服务项目"链接、底部"← 返回服务列表"按钮清理 |
| 4 | `ruoyi-ui/public/robots.txt` | 追加 `Disallow: /services.html`、`/contest.html`、`/service.html`（防搜索引擎收录） |

**未改动**：`services.html` / `contest.html` 页面本体及其后端接口、数据库 `book` 表服务数据、
后台管理端（admin）的对应菜单。

## 三、如何恢复（两步，可逆）

1. **取消导航隐藏**：在 12 个 HTML 中，把对应行
   `<!-- 暂隐藏导航：服务项目 -->` / `<!-- 暂隐藏导航：创客大赛 -->`
   还原为上一条 `<a href="services.html">服务项目</a>` / `<a href="contest.html">创客大赛</a>`。
   （`services.html` / `contest.html` 自身原来带 `class="active"`，一并还原。）
2. **恢复首页服务概览**：`home.html` 中把隐藏占位注释替换回原「04 服务概览」
   整段 `<section id="services">…</section>`（可从 git 历史取：`git show HEAD~1:ruoyi-ui/public/home.html`）。
3. robots 的三行 `Disallow` 按需删除。

## 四、遗留边界（上线/恢复前请确认）

- **URL 直输仍可访问**：隐藏只作用于入口；直接输入 `http://…/services.html`、
  `http://…/contest.html`、`http://…/service.html` 仍能打开页面（robots 只拦搜索引擎，不拦浏览器）。
  如要彻底封死直输，需在 `docker/nginx.conf` 增加：
  ```nginx
  location ~ ^/(services|contest|service)\.html$ { return 404; }
  ```
- **后台管理菜单仍在**：`/index`（admin 后台）的「服务项目」管理菜单未隐藏，若老板登录后台仍能看到。
- **内容真实性**：恢复前请确认两个栏目的展示内容（服务清单 / 大赛信息）与事实一致，
  尤其是创客大赛报名服务条目（`book` 表 `book_id=23`）与大赛规则、时间、奖项等文案。
