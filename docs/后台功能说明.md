# 🖥️ 后台功能说明（简单版）

> 面向日常运营人员，按后台菜单顺序介绍每个功能是做什么的、怎么用。
> 详细技术说明见《开发文档》；部署见《部署指南》。

## 一、登录

| 项 | 说明 |
|---|---|
| 地址 | `http://localhost/`（Docker 部署）；本机开发 `http://localhost:8081/` |
| 账号 | `admin`（超级管理员，全部功能）/ `editor`（内容编辑，仅内容类功能） |
| 口令 | 均为 `admin123`（首次登录后请修改：系统设置 → 用户管理） |

> 登录验证码默认关闭，可在「系统设置 → 站点设置」开启。

## 二、功能总览

后台功能分为四组：**内容运营**（日常最多用）、**成员与报名**、**运营辅助**、**系统设置**。

### 📝 内容运营

| 功能 | 说明 |
|---|---|
| **文章管理** | 官网新闻/政策文章的增删改查。支持：一键复制、批量置顶/下线/移动栏目、预约发布（到点自动上线）、定时下线、回收站还原、版本历史回滚、草稿自动保存 |
| **栏目管理** | 管理新闻/政策的分类树（最多 3 级），可调整顺序、配置栏目对应前台哪个页面 |
| **区块管理** | 官网首页及各栏目页的内容搭建核心。选模板（卡片/图文/数据等 20 种）→ 填内容 → 实时预览，所见即所得；支持手机/平板/桌面三种预览档位、跨页复制区块 |
| **页面管理** | 创建全新前台页面（自定义页），可配置页面入口（导航栏/更多菜单）与页头，用区块搭建内容 |
| **官网轮播** | 首页顶部轮播图管理：图片、标题、背景色/文字色、跳转链接 |
| **公告管理** | 顶部公告条：设置生效/失效时间（过期自动下架），点击看全文 |
| **内容统计** | 浏览量 Top20、栏目分布占比、近 30 天趋势 |

### 👥 成员与报名

| 功能 | 说明 |
|---|---|
| **成员管理** | 前台注册的成员列表：查看/停用/导出，重置密码（发邮箱验证码），查看登录记录 |
| **入驻申请** | 前台「入驻招商」页提交的申请：待处理/已处理/已拒绝流转；新申请自动邮件通知运营者 |
| **报名管理** | （服务业务重启中，TODO #1）服务报名/候补记录管理——恢复后可用 |

### 🛠️ 运营辅助

| 功能 | 说明 |
|---|---|
| **回收站** | 误删的文章/成员可在这里恢复或彻底删除；超期自动清理 |
| **使用帮助** | 后台使用提示 |

### ⚙️ 系统设置（一般管理员用）

| 功能 | 说明 |
|---|---|
| **站点设置** | 前台导航、页脚（关于我们/联系方式/加入我们）、联系电话/邮箱/公众号等站点级配置，保存后前台立即生效 |
| **参数配置** | 系统参数（验证码开关、会话时长、报名限额等）——按需修改，勿随意改动 |
| **用户管理** | 后台账号管理：改密码、增删账号 |
| **角色管理** | 角色与权限分配（超级管理员 / 内容编辑） |
| **菜单管理** | 后台菜单结构——**一般不要动**，改动无法随部署同步 |
| **邮件通知** | SMTP 发件配置与邮件模板（注册验证码/报名通知/入驻提醒等 10 个模板均可编辑） |

### 🔍 系统监控 / 系统工具（若依标准功能，一般用不到）

- 在线用户、操作日志、登录日志、定时任务（如回收站自动清理）、服务器监控等

## 三、日常操作速查

**发一篇新文章**：内容运营 → 文章管理 → 新增 → 填标题/正文/选栏目 → 保存（草稿）→ 发布
**改首页某个模块的内容**：内容运营 → 区块管理 → 找到对应区块 → 编辑 → 保存（前台立即生效）
**上传图片注意事项**：>2MB 且宽 >2000px 的图片会自动压缩；封面图建议 16:9
**发布公告**：公告管理 → 新增 → 设置生效时间（可设未来时间预约上线）
**看有哪些人提交了入驻申请**：成员与报名 → 入驻申请

## 四、注意事项

- **菜单管理/角色管理/参数配置请谨慎操作**——部分改动无法随部署自动同步，出问题需联系开发者
- 前台内容（文章/区块/栏目/配置）改完即生效，无需重启
- 后台账号口令定期修改；公网部署前务必完成《TODO #6 公网上线安全检查单》
