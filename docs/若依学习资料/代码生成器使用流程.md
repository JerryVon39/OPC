# 代码生成器使用流程（照做就能成）

> 适用：RuoYi-Vue 3.9.2 ｜ 目标：10~20 分钟做出一个完整业务模块（增删改查/搜索/导出/权限/日志全自动）
> 本手册以"读者管理"为例，实际做任何模块照此流程走一遍即可。

---

## 一、总览（先看全貌）

```
① 建表（数据库）→ ② 导入（界面）→ ③ 配置（界面）→ ④ 生成下载（界面）
→ ⑤ 部署文件（后端6+前端2）→ ⑥ 编译重启（后端）→ ⑦ 菜单入库 → ⑧ 刷新上线
```

---

## 二、第 ① 步：建表（数据库）

用 MySQL 命令行或图形工具（Navicat）执行：

```sql
CREATE TABLE reader (
  reader_id    bigint(20)    NOT NULL AUTO_INCREMENT COMMENT '读者ID',
  reader_name  varchar(50)   NOT NULL COMMENT '读者姓名',
  phone        varchar(20)   DEFAULT NULL COMMENT '手机号码',
  card_no      varchar(30)   DEFAULT NULL COMMENT '借书证号',
  reader_type  varchar(10)   DEFAULT NULL COMMENT '读者类型(字典:reader_type)',
  sex          char(1)       DEFAULT '0' COMMENT '性别(0男 1女 2未知)',
  birth_date   date          DEFAULT NULL COMMENT '出生日期',
  status       char(1)       DEFAULT '0' COMMENT '状态(0正常 1停用)',
  remark       varchar(500)  DEFAULT NULL COMMENT '备注',
  create_by    varchar(64)   DEFAULT '' COMMENT '创建者',
  create_time  datetime      DEFAULT NULL COMMENT '创建时间',
  update_by    varchar(64)   DEFAULT '' COMMENT '更新者',
  update_time  datetime      DEFAULT NULL COMMENT '更新时间',
  PRIMARY KEY (reader_id)
) ENGINE=InnoDB COMMENT='读者信息表';
```

**建表规范（生成器正常工作前提）**：

| 规则 | 示例 | 原因 |
|---|---|---|
| 主键：表名_id + bigint + 自增 | reader_id | 生成器识别主键 |
| 字段用下划线命名 | reader_name | 生成器自动转驼峰 readerName |
| 每个字段写 COMMENT | '读者姓名' | 注释会成为页面上的中文标签 |
| 审计字段固定四件套 | create_by/create_time/update_by/update_time | 生成器自动填充，页面不显示 |
| 需要下拉的字段注释里写字典 | 注释如 `读者类型(字典:reader_type)` | 提醒自己后面绑字典 |

**可选**：先建好字典（如 reader_type：学生/教师/普通读者），生成时直接绑定。

---

## 三、第 ② 步：导入表（界面操作）

1. 登录 → 系统工具 → **代码生成**
2. 点 **【导入】** 按钮
3. 弹出窗口中勾选刚才建的表（reader）→ 点 **【确定】**
4. 列表出现一行"reader 读者信息表"

> 导入失败常见原因：表名/字段名含非法字符；表已导入过（删掉列表记录重新导入即可）。

---

## 四、第 ③ 步：配置生成信息（最关键，三个页签）

点击列表行的 **【编辑】** 打开配置窗口：

### 页签一：基本信息

| 配置项 | 填什么 | 说明 |
|---|---|---|
| 表名 / 类名 | reader / Reader | 自动生成，别改 |
| 模块名 | system | 代码生成的包路径 |
| 功能名 | 读者管理 | 页面显示名 |
| 作者 | 你的名字 | 代码署名 |
| 上级菜单 | 系统管理 等 | 生成菜单 SQL 的挂载点 |
| 生成类型 | 单表（主表 CRUD） | 主子表需选"主子表" |

### 页签二：字段信息（逐行设置）

| 字段 | 列表 | 查询 | 表单 | 必填 | 显示类型 | 字典 |
|---|---|---|---|---|---|---|
| reader_id | ❌ | ❌ | ❌ | — | 主键 | — |
| reader_name | ✅ | ✅模糊 | ✅ | ✅ | 文本框 | — |
| phone | ✅ | ❌ | ✅ | ❌ | 文本框 | — |
| card_no | ✅ | ✅精确 | ✅ | ❌ | 文本框 | — |
| reader_type | ✅ | ✅精确 | ✅ | ❌ | **下拉框** | **reader_type** |
| sex | ✅ | ❌ | ✅ | ❌ | 单选按钮 | sys_user_sex |
| birth_date | ✅ | ❌ | ✅ | ❌ | 日期控件 | — |
| status | ✅ | ✅精确 | ✅ | ❌ | 单选按钮 | sys_normal_disable |
| remark | ✅ | ❌ | ✅ | ❌ | 文本域 | — |
| create_by 及以下 4 个 | ❌ | ❌ | ❌ | ❌ | — | — |

**操作要点**：
- 查询列选"模糊"或"精确"：文本字段用模糊，字典/状态字段用精确
- 字典类型列：下拉选择已建好的字典（没有就先在字典管理建）
- 显示类型：下拉框/单选按钮/日期控件/文本域 按需切换
- 每行修改自动保存，改完可直接关闭窗口

### 页签三：生成信息

- 生成方式：下载压缩包（默认）
- 其他默认即可

## 五、第 ④ 步：生成代码并下载

1. 回到代码生成列表
2. 点行的 **【生成代码】** 按钮
3. 浏览器下载 **xxx.zip**（xxx=表名）
4. 解压到桌面文件夹

**压缩包内 9 个文件**（生成器为你写的"一套完整业务代码"）：

```
main/java/com/ruoyi/system/          ← 后端代码（5个）
├── domain/Reader.java               实体类
├── mapper/ReaderMapper.java         数据库操作接口
├── service/IReaderService.java      业务接口
├── service/impl/ReaderServiceImpl.java  业务实现
└── controller/ReaderController.java 接口控制器
main/resources/mapper/system/
└── ReaderMapper.xml                 SQL 语句
bookMenu.sql 或 xxxMenu.sql          菜单 SQL（1个）
vue/                                  ← 前端代码（2个）
├── api/system/reader.js             接口定义
└── views/system/reader/index.vue    页面（列表+表单）
```

## 六、第 ⑤ 步：部署文件（复制到项目）

> 目标项目：`C:\Users\1\Desktop\ruoyi\RuoYi-Vue`

**后端 6 个** → 复制到 `ruoyi-system\` 下（目录不存在就创建）：

| 解压出的文件 | 目标目录 |
|---|---|
| domain/Reader.java | `ruoyi-system\src\main\java\com\ruoyi\system\domain\` |
| mapper/ReaderMapper.java | `ruoyi-system\src\main\java\com\ruoyi\system\mapper\` |
| service/IReaderService.java | `ruoyi-system\src\main\java\com\ruoyi\system\service\` |
| service/impl/ReaderServiceImpl.java | `ruoyi-system\src\main\java\com\ruoyi\system\service\impl\` |
| controller/ReaderController.java | `ruoyi-system\src\main\java\com\ruoyi\system\controller\`（新建目录） |
| resources/mapper/system/ReaderMapper.xml | `ruoyi-system\src\main\resources\mapper\system\` |

**前端 2 个** → 复制到 `ruoyi-ui\` 下：

| 解压出的文件 | 目标目录 |
|---|---|
| vue/api/system/reader.js | `ruoyi-ui\src\api\system\reader.js` |
| vue/views/system/reader/index.vue | `ruoyi-ui\src\views\system\reader\index.vue` |

> 技巧：整体复制 `main` 和 `vue` 两个文件夹粘贴到对应位置，Windows 自动合并目录。

## 七、第 ⑥ 步：编译重启后端

> 前端 dev server 会自动热更新，**不用重启前端**；后端代码在 jar 里，必须重新编译。

```bash
# 1. 停掉正在运行的后端（任务管理器结束 java.exe，或 stop-all.bat）
# 2. 在项目根目录执行：
mvn -pl ruoyi-admin -am package -DskipTests
# 3. 启动新 jar：
java -jar ruoyi-admin/target/ruoyi-admin.jar
```

> ⚠️ 编译报错 "Unable to rename ruoyi-admin.jar" = 后端还在运行占用文件，先停再编。

## 八、第 ⑦ 步：菜单入库（两种方式任选）

### 方式 A：执行菜单 SQL（快）

打开解压包里的 `readerMenu.sql`，内容是一个菜单（读者管理）+ 5 个按钮（查询/新增/修改/删除/导出），在 MySQL 里执行：

```bash
mysql -uroot -ppassword ry-vue < readerMenu.sql
```

### 方式 B：界面手动添加（教学推荐，理解菜单结构）

1. 系统管理 → 菜单管理 → 新增
2. 填写：菜单类型"菜单"、菜单名称"读者管理"、路由地址 reader、组件路径 system/reader/index、权限字符 system:reader:list
3. 保存后在该菜单下再新增 5 个"按钮"类型菜单（查询/新增/修改/删除/导出，权限字符 system:reader:query/add/edit/remove/export）

---

## 九、第 ⑧ 步：验证上线

1. 浏览器 **Ctrl+F5 强刷**（前端可能有缓存）
2. 登录 → 找到"读者管理"菜单（在配置的上级菜单下）
3. 测试：新增一条读者 → 列表显示 → 编辑 → 搜索 → 导出 Excel → 删除
4. 验证权限：给普通角色去掉"读者删除"权限 → ry 登录 → 删除按钮消失

## 十、常见问题速查

| 问题 | 解决 |
|---|---|
| 导入时找不到刚建的表 | 检查表建在 ry-vue 库；表名含非法字符 |
| 生成的页面中文是表名字 | 建表时没写 COMMENT，字段注释补全后"同步"再生成 |
| 下拉框没选项 | 字典没建或没绑定，回编辑窗口重新选字典类型 |
| 保存时报错/接口 500 | 看后端窗口日志；检查字段类型与实体不匹配（如 date 字段类型） |
| 菜单点了 404 | 菜单管理里组件路径写错（应为 system/reader/index） |
| 改动生成代码不生效 | 前端 Ctrl+F5；后端需重新编译重启 |
| 想重新生成 | 代码生成列表删掉该行记录，重新导入即可 |

## 十一、进阶：主子表（如订单+订单明细）

1. 建两张表：主表（order 订单）+ 子表（order_item 明细，含外键 order_id）
2. 导入两张表 → 编辑**主表** → 生成类型选"**主子表**" → 子表选 order_item
3. 生成的页面：主表列表 + 点击行展开子表明细编辑
4. 其余流程完全相同
