# 🛡️ 万事屋 · 部署与运维指南

> 面向开发学习与演示场景，覆盖：本机启动 → 正式部署 → 数据库备份恢复 → 升级回滚

---

## 一、本机开发环境启动（每天开工）

依赖已装好的环境：**JDK 17、Maven、MySQL 8、Redis、Node.js**

1. 启动 MySQL 和 Redis（若没开机自启）
2. 启动后端：
   ```bash
   cd RuoYi-Vue
   mvn -pl ruoyi-admin -am package -DskipTests   # 修改代码后需重新打包
   java -jar ruoyi-admin/target/ruoyi-admin.jar   # 默认 8080 端口
   ```
3. 启动前端（开发模式，代码改动自动生效）：
   ```bash
   cd ruoyi-ui
   npm run dev
   ```
4. 访问：
   - 后台：`http://localhost:端口/`（admin / admin123）
   - 前台万事屋：`http://localhost:端口/shop.html`

> ⚠️ 端口以 `ruoyi-ui/vue.config.js` 中的 `port` 为准（默认 80，被占用时可改）。

## 二、正式部署（把系统拿出去给别人用）

部署到一台**公网服务器**（Windows / Linux 均可），核心三步：**数据库 → 后端 jar → 前端静态文件**。

### 1. 数据库（服务器上装 MySQL 8 + Redis）

```bash
# 依次导入三个脚本（顺序不能乱，business_init.sql 幂等可重复执行）
mysql -uroot -p < sql/ry_20260417.sql
mysql -uroot -p < sql/quartz.sql
mysql -uroot -p < sql/business_init.sql
```

### 2. 后端（打包成 jar，随系统启动）

```bash
mvn -pl ruoyi-admin -am package -DskipTests
```

修改两个配置后启动：

| 配置文件 | 改什么 |
|---|---|
| `ruoyi-admin/src/main/resources/application-druid.yml` | 数据库地址 / 账号 / 密码 |
| `ruoyi-admin/src/main/resources/application.yml` | 服务端口（默认 8080） |

```bash
java -jar ruoyi-admin/target/ruoyi-admin.jar
```

> 💡 长期运行建议用 NSSM 把 jar 注册成 Windows 服务（`nssm install 万事屋后端 "java" "-jar 路径\ruoyi-admin.jar"`），开机自启、崩溃自动拉起。

### 3. 前端（构建静态文件 + Nginx）

```bash
cd ruoyi-ui
npm install
npm run build:prod        # 生成 dist/ 静态文件
```

把 `dist` 目录放到服务器，Nginx 配置示例（Linux）：

```nginx
server {
    listen 80;
    server_name 你的域名或IP;

    # 前端页面
    location / {
        root /www/book-system/dist;
        try_files $uri $uri/ /index.html;
    }

    # 后端接口代理（前端请求 /prod-api 前缀）
    location /prod-api/ {
        proxy_pass http://127.0.0.1:8080/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 上传的封面图片（后端本地存储）
    location /profile/ {
        proxy_pass http://127.0.0.1:8080;
    }
}
```

> 💡 Windows 服务器也可以直接用 Nginx for Windows，配置相同。

## 三、数据库备份与恢复（重要！）

### 备份（每天一次，挂定时任务）

`scripts/backup-db.bat` 一键备份整个业务库，备份文件带日期时间戳：
`backup\ry-vue_20260813_0945.sql`

**设置每天自动备份（Windows）**：
1. 按 `Win + R` → 输入 `taskschd.msc` 打开"任务计划程序"
2. 右侧"创建基本任务" → 名称"万事屋数据库备份"
3. 触发器选"每天"、时间设为 23:00
4. 操作选"启动程序" → 程序选 `scripts\backup-db.bat`
5. 完成。以后每天 23 点自动生成一份备份

**建议**：定期把 `backup` 文件夹复制到 U 盘 / 网盘，防止硬盘损坏丢数据。

### 恢复（出问题时）

```bash
mysql -uroot -p < backup\ry-vue_20260813_0945.sql
```

> ⚠️ 恢复会**覆盖当前数据**，恢复前务必先备份一次现场数据。

## 四、升级与回滚

本项目所有改动都提交在 Git 里，升级 = 拉最新代码重新打包：

```bash
git pull github master      # 拉取最新代码
mvn -pl ruoyi-admin -am package -DskipTests   # 重新打包后端
cd ruoyi-ui && npm run build:prod              # 重新构建前端
```

**数据库结构有变化时**（例如新表、新字段），先执行 `sql/business_init.sql`（幂等，安全）。

**回滚** = 用 Git 历史回到上一个可用版本：

```bash
git checkout 上一个提交号   # 例如 git checkout bce94ff1
```

## 五、常见问题排查

| 现象 | 检查 |
|---|---|
| 页面打不开 | 前端 npm run dev 是否在运行；端口是否被占用 |
| 接口 404/502 | 后端是否启动；Nginx 代理地址是否正确 |
| 缓存监控报"cannot read redis info" | Redis 安装路径不能含中文/反斜杠转义问题，建议装到 `C:\Redis` |
| 中文乱码 | 数据库连接串加 `characterEncoding=utf8`；导入 SQL 用 `--default-character-set=utf8mb4` |
| 上传图片后前台不显示 | 确认 `/profile/` 代理配置（Nginx 段）或前端 /dev-api 前缀 |
