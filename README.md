# 🏪 万事屋 · 图书管理系统

> 基于 **RuoYi-Vue 3.9.2**（Spring Boot + Vue 2）从零二次开发的图书借阅 + 购书一体化系统
> 后台面向管理员 · 前台"万事屋"面向读者 · 完整业务闭环 · 学习与演示用

---

## ✨ 功能全景

### 🛍️ 书店前台「万事屋」（匿名可访问，`shop.html`）

- 🔍 **搜索**：书名 / 作者 模糊搜索，分类 Tab 切换，**一键返回全部**（logo / 全部 Tab / 清除筛选）
- 🖼️ **图书展示**：竖版封面卡片（后台可上传真实封面）、在售/下架/库存紧张标签（阈值后台可配）、热门推荐 Top5
- 📖 **图书详情**：基本信息 + 内容简介分区展示，ISBN、价格、库存等完整信息
- 📝 **读者登记**：顾客自助登记，借书证号**后端自动生成**（防伪造/占坑）
- 👤 **读者登录**：姓名 + 借书证号（挂失/停用证号自动拒绝）
- 📚 **借书**：一键借书，应还日期自动 +30 天；**我的借阅**查看剩余天数、**自助续借**
- 🛒 **购书**：购物车（数量增减/移除/合计）→ 一键结算 → 库存自动 -1
- 📦 **我的订单**：按证号/登录态查询，**自助取消订单**（库存自动回补）
- 📢 **公告横幅**：自动轮播 + 长公告跑马灯滚动 + 当日可关闭
- 📱 **手机自适应**：≤768px 自动切换移动版布局（导航多行 / 两列卡片 / 弹窗自适应）
- 🎨 **品牌视觉**：墨绿+米金暖木书店调、吸顶导航、胶囊分类、骨架屏加载、页脚三栏
- 🔄 **前后台切换**：前台导航与后台顶栏一键互跳

### 🔧 后台管理（管理员视角）

- 📚 **图书管理**：增删改查、**封面图片上传**、ISBN/简介、在架/下架、库存预警标签、Excel 导入导出
- 👤 **读者管理**：证号自动生成/手填、类型字典、性别/状态、停用/挂失、借阅历史入口、Excel 导出
- 🔄 **借阅管理**：借书/还书/续借、逾期红色标记、按图书/读者筛选、**Excel 导出**
- 📦 **订单管理**：待付款 → **收款** → 完成（仅待付款可取消，取消自动回滚库存），订单删除
- 💰 **逾期罚款**：还书自动结算罚款（0.10 元/天可配）→ 欠费冻结借书 → 收银收款清欠 → 看板欠费总额
- 🪪 **挂失补办**：前台自助申请（姓名+登记手机号，证号丢失也能补办）+ 后台一键补办，旧证号作废、历史快照保留
- 📱 **我的信息**：前台登录后自助修改手机号（证号+姓名校验）
- 👤 **登录态优化**：登录后自动隐藏"读者登记"入口，退出恢复
- 📊 **数据看板**：首页 9 项业务统计（含欠费总额）+ 热门图书 Top5 图表 + 快捷入口
- 📈 **借阅统计**：热门图书 Top10、读者借阅排行 Top10
- 🗣️ **公告管理**：催还通知自动发布/回收（见下）
- 🔐 **角色权限分级**：图书管理员 / 收银专员 / 统计访客 三种角色 + 测试账号（RBAC 完整落地）
- 📚 **差异化借阅规则**：按读者类型区分借阅上限与借期（学生 5 本 30 天 / 教师 10 本 60 天 / 普通 3 本 30 天，参数可配）
- 🛡️ **数据一致性**：借阅/订单快照冗余——删除读者或图书后历史记录依然完整可查

### 🤖 自动化（Quartz 定时任务）

| 任务 | 时间 | 行为 |
|---|---|---|
| 逾期检查 | 每天 0:00 | 自动标记逾期借阅 |
| 逾期催还公告 | 每天 9:00 | 有逾期自动发布催还公告（当天只发一次） |
| 公告回收 | 还书时触发 | 逾期书还清 → 公告自动删除；仍有逾期 → 重新汇总发布 |

## 🚀 快速开始（本机开发）

### 环境要求
JDK 17、Maven 3.6+、Node.js 16+、MySQL 8、Redis

### 启动步骤

```bash
# 1. 初始化数据库（依次导入）
mysql -uroot -p < sql/ry_20260417.sql        # 若依系统表
mysql -uroot -p < sql/quartz.sql             # 定时任务表
mysql -uroot -p < sql/business_init.sql      # 业务表+字典+菜单+订单表（幂等，可重复执行）

# 2. 配置数据库连接
#    编辑 ruoyi-admin/src/main/resources/application-druid.yml（账号密码）

# 3. 启动后端
mvn -pl ruoyi-admin -am package -DskipTests
java -jar ruoyi-admin/target/ruoyi-admin.jar

# 4. 启动前端
cd ruoyi-ui
npm install
npm run dev
```

- 后台地址：`http://localhost:8081/`（默认账号 admin / admin123）
- 前台万事屋：`http://localhost:8081/shop.html`（顾客视角，无需登录）

> 💡 前端端口在 `ruoyi-ui/vue.config.js` 中配置（默认 80，本机被占用时可改端口）。完整启动/排错细节见《使用指南》。

## 📁 项目结构

```
├── ruoyi-admin        # 启动模块（配置、定时任务 BorrowTask）
├── ruoyi-framework    # 框架层（安全/拦截器/切面）
├── ruoyi-system       # 业务模块（book/reader/borrow/order 的 controller/service/mapper）
├── ruoyi-common       # 公共工具
├── ruoyi-generator    # 代码生成器
├── ruoyi-quartz       # 定时任务框架
├── ruoyi-ui           # 前端（views/system/{book,reader,borrow,order}、public/shop.html）
├── scripts            # 运维脚本（数据库备份 backup-db.bat）
├── docs               # 文档（使用指南/代码生成器流程/部署指南）
└── sql                # 数据库脚本（business_init.sql 业务初始化，幂等）
```

**核心业务代码位置**：
- 借阅业务规则（借书/还书/库存联动/逾期/公告回收）：`ruoyi-system/.../service/impl/BorrowRecordServiceImpl.java`
- 购书业务（校验/下单/库存联动/事务）：`ruoyi-system/.../service/impl/ShopOrderServiceImpl.java`
- 逾期定时任务：`ruoyi-admin/.../quartz/task/BorrowTask.java`
- 书店前台：`ruoyi-ui/public/shop.html`
