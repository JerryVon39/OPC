# 🏪 万事屋 · 图书管理系统

> 基于 **RuoYi-Vue 3.9.2**（Spring Boot + Vue 2）从零二次开发的图书借阅 + 购书一体化系统
> 后台面向管理员 · 前台"万事屋"面向读者 · 完整业务闭环 · 学习与演示用

---

## ✨ 功能全景

### 🛍️ 书店前台「万事屋」（匿名可访问，`shop.html`）

- 🔍 **搜索**：书名 / 作者 模糊搜索，分类 Tab 切换，**一键返回全部**（logo / 全部 Tab / 清除筛选）
- ⚡ **搜索联想**：边打字边弹出匹配书名（百度式下拉，防抖 200ms / ↑↓ 选择 / 回车选中），点击联想项直接搜索
- 🔀 **搜索排序**：结果可按"借阅最多 / 最新出版"排序；无结果时显示引导卡片 + **申请荐购**按钮（不再空荡荡）
- 📝 **荐购管理**：读者提交想看的书（书名/作者/附言）→ 后台「荐购管理」处理（待处理/已处理/已拒绝，同书名防重复）
- ⚡ **乐观 UI**：借书 / 续借 / 预约点击瞬间按钮即变（借阅→已借出、续借→已续借、预约→已预约），出错自动回滚；锁粒度按书拆分，并行操作互不阻塞
- 🖼️ **图书展示**：竖版封面卡片（后台可上传真实封面）、在售/下架/库存紧张标签（阈值后台可配）、热门推荐 Top5
- 📖 **图书详情**：基本信息 + 内容简介分区展示，ISBN、价格、库存等完整信息
- 📝 **读者登记**：顾客自助登记，借书证号**后端自动生成**（防伪造/占坑）；**电子邮箱必填**（用于借阅/预约等自动邮件通知，个人中心可改）
- 👤 **读者登录**：姓名 + 借书证号（挂失/停用证号自动拒绝）
- 📚 **借书**：一键借书，应还日期自动 +30 天；**我的借阅**查看剩余天数、**自助续借**
- 🛒 **购书**：购物车（数量增减/移除/合计）→ 一键结算 → 库存自动 -1
- 📦 **我的订单**：按证号/登录态查询，**自助取消订单**（库存自动回补）
- 📢 **公告横幅**：自动轮播 + 长公告跑马灯滚动 + 当日可关闭
- 🎠 **轮播图管理**：后台可增删改前台轮播（上传图片/排序/启用停用，无图渐变背景）
- 📝 **BBCODE 富文本**：简介/公告支持 [b]粗体[/b] [quote]引用[/quote] [url]链接[/url] 等 10 种标签（防 XSS），后台工具栏一键插入
- 📊 **店铺数据条**：横幅下方实时统计（馆藏/读者/今日借出/今日订单）
- 🆕 **新书上架角标**：近 7 天入库的图书显示"新"角标
- 🪟 **弹窗体验**：点击弹窗外空白自动关闭
- 📱 **手机自适应**：≤768px 自动切换移动版布局（导航多行 / 两列卡片 / 弹窗自适应）
- 🎨 **品牌视觉**：墨绿+米金暖木书店调、吸顶导航、胶囊分类、骨架屏加载、页脚三栏
- 🔄 **前后台切换**：前台导航与后台顶栏一键互跳

### 🔧 后台管理（管理员视角）

- 📚 **图书管理**：增删改查、**封面图片上传**、ISBN/简介、在架/下架、库存预警标签、Excel 导入导出
- 🎚️ **上下架开关**：列表状态列拨动开关直接上架/下架（不用进编辑页）；有预约中/可借预约的图书禁止下架（联动校验）
- 📥 **Excel 批量导入**：图书/读者页上传 xlsx 批量新增（模板下载、逐行校验、同名/证号判重跳过、失败行号明细提示；读者证号留空自动生成）
- 🚨 **库存预警**：后台首页自动列出库存低于阈值（book.stock.warn 可配）的在架书提醒补货，点击直达低库存列表
- 👤 **读者管理**：证号自动生成/手填、类型字典、性别/状态、停用/挂失、借阅历史入口、Excel 导出
- 🔄 **借阅管理**：借书/还书/续借、逾期红色标记、按图书/读者筛选、**Excel 导出**
- 📦 **订单管理**：待付款 → **收款** → 完成（仅待付款可取消，取消自动回滚库存），订单删除
- 💰 **逾期罚款**：还书自动结算罚款（0.10 元/天可配）→ 欠费冻结借书 → 收银收款清欠 → 看板欠费总额
- 🪪 **挂失补办**：前台自助申请（姓名+登记手机号，证号丢失也能补办）+ 后台一键补办，旧证号作废、历史快照保留
- 📱 **我的信息**：前台登录后自助修改手机号/邮箱（证号+姓名校验）
- 📧 **自动邮件通知**：借书成功 / 续借成功 / 预约成功 / 预约可借提醒 / 荐购处理结果 自动发邮件（QQ 邮箱 SMTP，异步"尽力而为"不阻断业务，授权码走环境变量 `MAIL_AUTH_CODE` 不进代码库）
- 👤 **登录态优化**：登录后自动隐藏"读者登记"入口，退出恢复
- 📊 **数据看板**：首页 9 项业务统计（含欠费总额）+ 热门图书 Top5 图表 + 快捷入口
- 📈 **借阅统计**：热门图书 Top10、读者借阅排行 Top10
- 🗣️ **公告管理**：催还通知自动发布/回收（见下）
- ♻️ **回收站（误删恢复）**：删除图书/读者先进回收站（含删除人/时间快照），可还原（原 ID/证号被占用自动换新）、彻底删除、清空；有未还借阅/待处理订单/预约中的仍拦截不入站
- 🔐 **角色权限分级**：图书管理员 / 收银专员 / 统计访客 三种角色 + 测试账号（RBAC 完整落地）
- 📚 **差异化借阅规则**：按读者类型区分借阅上限与借期（学生 5 本 30 天 / 教师 10 本 60 天 / 普通 3 本 30 天，参数可配）
- 🛡️ **数据一致性**：借阅/订单快照冗余——删除读者或图书后历史记录依然完整可查

## 🚀 一键启动（Docker，推荐新用户）

从 GitHub 克隆仓库后，**只需安装 Docker**（Windows: Docker Desktop；无需 MySQL/Redis/Java/Node）：

```bash
git clone https://github.com/JerryVon39/book-system.git
cd book-system

# Windows：双击 scripts\start-all.bat，或在命令行运行
scripts\start-all.bat
# Linux/macOS：
./scripts/start-all.sh
```

脚本会自动：检查 Docker → 生成 `.env`（默认配置可直接启动）→ 拉取线上镜像并启动 MySQL/Redis/后端/前端 → 等待后端就绪。

- 管理后台：`http://localhost/`（默认账号 admin / admin123，首次登录请修改密码）
- 读者前台：`http://localhost/shop.html`
- 停止：`scripts\stop-all.bat` / `./scripts/stop-all.sh`（数据保留，重跑 start 即恢复）

> 💡 可选配置：编辑 `.env` 可设置数据库/Redis 口令、JWT 密钥（`TOKEN_SECRET`，生产务必设置）、邮件通知（`MAIL_USERNAME`/`MAIL_AUTH_CODE`，QQ 邮箱 SMTP 授权码）。全部口令默认值仅面向演示，**生产部署务必修改**。
>
> 💡 需要自己改代码时，可 `docker compose up -d --build` 用本地代码重新构建镜像（compose 保留了 build 配置）。

## 🚀 快速开始（本机开发，脚本一键启动）

已有 JDK 17 / Node.js（以及本机 MySQL、Redis，或用 Docker）的开发者，推荐用脚本：

```bash
git clone https://github.com/JerryVon39/book-system.git
cd book-system

# Windows：双击 scripts\start-local.bat，或在命令行运行
scripts\start-local.bat
# Linux/macOS：
./scripts/start-local.sh
```

脚本自动完成：生成 `.env`（默认配置可直接启动）→ 启动/复用 MySQL 与 Redis（本机原生优先，无则自动用 Docker 拉起容器）→ 首次自动建库导入 `sql/` 初始化脚本、已有库自动跑增量升级 → 构建并启动后端（8080）→ 启动前端（8081）→ 打印访问地址。

- 管理后台：`http://localhost:8081/`（默认账号 admin / admin123，首次登录请修改密码）
- 读者前台：`http://localhost:8081/shop.html`
- 前端端口可在 `.env` 用 `FE_PORT` 修改；本机原生 MySQL/Redis 不在 PATH 时可设 `TOOLS_HOME` 指向其安装目录
- 停止：`scripts\stop-local.bat` / `./scripts/stop-local.sh`（数据保留，重跑 start 即恢复）

## 🔐 前台读者登录会话（2026-08-17 加固）

前台读者登录后由后端签发 **短期会话 token**（存 Redis，30 分钟有效），我的借阅/预约/订单查询与借书/续借/取消等操作均需携带 `sessionToken` 并由后端校验归属，不再信任前端提交的借书证号，降低冒用他人证号的风险。未登录时相关入口会提示先登录，不再支持手输证号匿名查询。

## 🛡️ 并发与数据一致性（持续加固）

- 还书、前台/后台取消订单、删除待付款订单全部改为 **原子状态转换**（`WHERE ... AND status = 期望值`），只有状态转换成功的请求才回补库存，并发重复操作不会造成库存虚高；订单号唯一索引（`uk_order_no`）+ 随机后缀，下单不重号；
- （2026-08-18）借书/预约/下单/删除读者以 **FOR UPDATE 锁读者行**（删除图书锁图书行），同一读者的并发操作串行化、检查与写入原子化；配合 **READ_COMMITTED 隔离级别**，加锁后的检查查询读取最新已提交数据——REPEATABLE READ 的旧快照会让并发重复借阅/重复预约漏检、批量删除第 2 个起 id 的检查失真，故这几个写路径显式声明 READ_COMMITTED；
- 单元测试补至 **96 用例**（含并发取消失败不回补库存、加锁后读者被并发删除等场景）。
